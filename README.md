# Weather Dashboard 🌦️

A responsive Weather Dashboard built using HTML, CSS and JavaScript.

## About the Project
Weather Dashboard is a web application that allows users to search for different cities and check their current weather conditions and forecasts.

## Features
- Search weather by city name
- Display current weather information
- Weather forecast
- Loading indicator
- Error handling
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## API
Weather data is provided by OpenWeatherMap.

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
